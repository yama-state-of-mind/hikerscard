1全体像（テーブル7つ）

引き継ぎ資料では6つと書いたが、blocks と reports を分けて数えると7つになる。users はSupabaseが管理する auth.users をそのまま使うので自作しない。

2各テーブルの定義

profilesカードの中身 中心テーブル

auth.usersと1対1。アカウント作成と同時に自動で1行作られる。

カラム型説明
iduuid主キー。auth.users.idと同じ値
public_idtextURL用のランダム6文字。連番にしない（総当たりで辿られるのを防ぐ）
card_nointカード番号（連番）。表示専用。URLからは辿れない 新規
display_nametext表示名。20文字まで。空のうちは公開されない
commenttextひとこと。50文字まで
type_codetext診断タイプ（例: PGLA）。空＝未診断でも公開される
axis_pe / sg / lf / casmallint診断の4軸。1文字目側への寄り0〜100。診断から自動
created_at / updated_attimestamptz作成・更新日時（自動）
MVPでは公開範囲のカラムを持たない。全項目公開で始める。Phase 2で vis_* カラムを足すが、取得はRPC経由にしてあるので仕組みの作り直しは発生しない。
退会も猶予期間を持たない。Phase 1は退会＝即削除。deleted_at はPhase 4で追加。

mountains山マスタ ／ climbed_mountains登ったことがある山

MVPでは百名山100座のみ。全ユーザー共通の読み取り専用マスタ。

カラム型説明
mountains
idsmallint主キー（連番）
nametext山名（重複不可）
kanatextかな検索用。「やり」で槍ヶ岳が出るようにする。後付けだと全件入力し直しになるので最初から入れる
elevationsmallint標高（表示用）
areatextエリア名（絞り込み用）
is_hyakumeizanboolean百名山バッジと踏破数の判定に使用
difficultysmallint難易度1〜5。MVPでは null のまま。Phase 2で埋める
climbed_mountains（主キー＝user_id＋mountain_idの組）
user_iduuidprofiles.idへの外部キー
mountain_idsmallintmountains.idへの外部キー
created_attimestamptz登録日時
登った日付は持たない。日付を入れると記録アプリに近づき、YAMAPと競合し始める。「登ったことがある」だけで十分。
踏破数は専用カラムを持たない。climbed × is_hyakumeizan を数えるだけにすれば、追加・削除で数字がズレる事故が起きない。

exchange_tokens有効期限つきQR 新規

「その場で会っている」ことを技術的に担保する仕組み。このサービスの根幹。

カラム型説明
tokentext主キー。推測できないランダム文字列（16文字）
owner_iduuid発行した人
expires_attimestamptz有効期限。発行から10分
revokedboolean手動で無効化したか（「QRを閉じる」操作）
use_countint何人が使ったか。有効期限内なら複数人可
created_attimestamptz発行日時
QRとURLは同じトークンを使う。QRが読み取れない場面（画面の明るさ、カメラの不調、相手が操作に不慣れ）に備えた代替手段。有効期限が10分なので、URLをメッセージアプリで送れたとしても、その場にいない人が使う余地はほとんどない。制約は期限が担保しているので、渡し方が2通りあっても原則は崩れない。
期限切れのトークンは、削除せず残す（不正利用の調査に使えるため）。

exchanges交換の記録 新規

「誰と誰が交換したか」を1行で表す。1組につき常に1行。

カラム型説明
iduuid主キー（自動生成）
user_auuid2人のIDのうち小さい方（並びを固定する）
user_buuid大きい方
first_met_attimestamptz初回の交換日。再交換しても上書きしない
last_exchanged_attimestamptz最後に交換した日時
交換は相互。片方がQRを読めば、両者のコレクションに入る。申請も承認もない。
IDの小さい方をuser_a、大きい方をuser_bに固定することで、「AとBの組は1行まで」を主キーで強制できる。どちらが読み取ったかは記録しない（対等な関係なので）。
再交換は上書きしつつ初回交換日は残す。相手のカードが更新されたら反映したいが、初めて会った日は記憶として残す価値がある。

blocksブロック ／ reports通報

交換機能と同時リリース。問題が起きてから作ると、起きた人を守れない。

カラム型説明
blocks（主キー＝blocker_id＋blocked_idの組）
blocker_id / blocked_iduuidブロックした人 / された人
reports
iduuid主キー
reporter_iduuid通報した人（未ログインなら null）
reported_iduuid通報された人
reasontext通報理由（選択式）
detailtext自由記述（1000字まで・任意）
statustextopen / resolved。運営用
ブロックの効果：①既存の交換記録を自動削除（トリガー）　②相手のQRを読んでも交換できない　③相手にはカードが「存在しない」ように見える　④相手に通知は行かない
設定画面にブロック中のリストを用意し、解除できるようにする。

3交換の仕組み（確定事項）

項目決定
相互／片方向相互。片方が読めば両者のコレクションに入る。1回の操作で済み、体験が軽い
有効期限10分。短いほど「その場で会っている」感が強い。長いと後から交換できてしまい原則が薄れる
1つのQRで
何人と交換		有効期限内なら複数人。山行会で5人と交換する場面に対応。撮影されるリスクは期限で抑える
再交換上書きしつつ初回交換日は残す
URL交換許す。QRと同じトークンを使う。QRが読めない場面の代替手段として必要
手動無効化できる。「QRを閉じる」で revoked を立てる

交換の流れ

1
Aが「交換する」を押す → issue_exchange_token() がトークンを発行（10分有効）
2
画面にQRとURLが表示される
3
Bが読み取る → redeem_exchange_token() を実行
4
関数の中で検証：期限内か／無効化されていないか／自分自身でないか／ブロック関係がないか
5
問題なければ exchanges に1行追加（既にあれば last_exchanged_at のみ更新）。両者のコレクションに相手が現れる
交換の処理をDB内の関数（RPC）で行うのが重要。フロント側でINSERTさせると、期限やブロックの検証をすり抜けられる。関数の中で検証すれば、不正な交換は原理的に作れない。

4RLSポリシー一覧

RLS＝「誰がどの行を読み書きできるか」をDB自体に持たせるルール。フロントにバグがあってもDBが最後の砦になる。全テーブルで有効化する。

テーブルルール
profiles読み：本人のみ（他人のカードはRPC経由）／更新：本人のみ。public_id・card_id・created_at は本人でも変更不可（トリガーで保護）
mountains読み：誰でも（ログイン不要）／書き：不可
climbed_
mountains		読み：本人＋他ユーザー（MVPは全公開）／追加・削除：本人のみ
exchange_
tokens		読み：発行者本人のみ（他人のトークンは見えない）／作成・無効化：本人のみ。交換時の検証はRPC内で行う
exchanges読み：当事者2人のみ／作成：直接は不可。RPC経由のみ／削除：当事者どちらでも（交換の取り消し）
blocks読み・作成・削除：ブロックした本人のみ。作成と同時に交換記録を自動削除（トリガー）
reports作成：誰でも（未ログイン可）／読み：ユーザーは誰も読めない（運営のみ）

5Phase 2以降への備え

MVPでは作らないが、後から追加するときに作り直しが発生しないようにしてある。

将来の追加なぜ手戻りしないか
公開範囲の設定カードの取得を最初からRPC経由にしてあるので、関数の中に判定を足すだけ。クライアント側で隠す方式だと作り直しになる
行ってみたい山climbed_mountains と同じ形のテーブルを足すだけ
百名山以外の山is_hyakumeizan = false でINSERTするだけ。踏破リングは true の行だけを数えているので分母は動かない
ルート登録routes / climbed_routes を新設する。climbed_mountains には手を入れない。混ぜると主キーの都合で「同じ山を2ルート」が表せず、後から主キーを変えるのはデータ移行が発生する本物の作り直しになる
退会の猶予期間profiles に deleted_at を足し、RPCに1行チェックを足すだけ
カードのカスタマイズprofiles にテーマ・背景のカラムを足すだけ

-- ---------- 山マスタ ----------
create table public.mountains (
  id smallint generated by default as identity primary key,
  name text not null unique,
  kana text not null,
  elevation smallint,
  area text,
  is_hyakumeizan boolean not null default true,
  difficulty smallint check (difficulty between 1 and 5)
);
create index mountains_kana_idx on public.mountains (kana);

-- ---------- プロフィール（カードの中身） ----------
create table public.profiles (
  id uuid primary key references auth.users(id) on delete cascade,
  public_id text unique not null,
  card_no int generated by default as identity,
  display_name text not null default '' check (char_length(display_name) <= 20),
  comment text check (char_length(comment) <= 50),
  type_code text check (type_code ~ '^[A-Z]{4}$'),
  axis_pe smallint check (axis_pe between 0 and 100),
  axis_sg smallint check (axis_sg between 0 and 100),
  axis_lf smallint check (axis_lf between 0 and 100),
  axis_ca smallint check (axis_ca between 0 and 100),
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);
create unique index profiles_card_no_idx on public.profiles (card_no);

-- ランダム文字列（紛らわしい文字 l/1/o/0 を除いた31文字）
create or replace function public.random_public_id(len int default 6)
returns text language sql volatile as $$
  select string_agg(
    substr('abcdefghjkmnpqrstuvwxyz23456789',
           (floor(random() * 31) + 1)::int, 1), '')
  from generate_series(1, len);
$$;

-- 交換トークン用（英数字・推測されにくい16文字）
create or replace function public.random_token(len int default 16)
returns text language sql volatile as $$
  select string_agg(
    substr('abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789',
           (floor(random() * 62) + 1)::int, 1), '')
  from generate_series(1, len);
$$;

-- アカウント作成時にprofiles行を自動作成
create or replace function public.handle_new_user()
returns trigger language plpgsql security definer set search_path = public as $$
declare new_id text;
begin
  loop
    new_id := public.random_public_id(6);
    exit when not exists (select 1 from public.profiles where public_id = new_id);
  end loop;
  insert into public.profiles (id, public_id) values (new.id, new_id);
  return new;
end;
$$;
create trigger on_auth_user_created
  after insert on auth.users
  for each row execute function public.handle_new_user();

-- 変更不可カラムの保護＋updated_at自動更新
create or replace function public.protect_profile_fields()
returns trigger language plpgsql as $$
begin
  new.updated_at := now();
  new.public_id  := old.public_id;   -- URLは変更不可
  new.card_no    := old.card_no;     -- カード番号も変更不可
  new.created_at := old.created_at;
  return new;
end;
$$;
create trigger on_profile_update
  before update on public.profiles
  for each row execute function public.protect_profile_fields();

-- ---------- 登ったことがある山 ----------
create table public.climbed_mountains (
  user_id uuid not null references public.profiles(id) on delete cascade,
  mountain_id smallint not null references public.mountains(id),
  created_at timestamptz not null default now(),
  primary key (user_id, mountain_id)
);

-- ---------- ブロック・通報 ----------
create table public.blocks (
  blocker_id uuid not null references public.profiles(id) on delete cascade,
  blocked_id uuid not null references public.profiles(id) on delete cascade,
  created_at timestamptz not null default now(),
  primary key (blocker_id, blocked_id),
  check (blocker_id <> blocked_id)
);

create table public.reports (
  id uuid primary key default gen_random_uuid(),
  reporter_id uuid references public.profiles(id) on delete set null,
  reported_id uuid not null references public.profiles(id) on delete cascade,
  reason text not null,
  detail text check (char_length(detail) <= 1000),
  status text not null default 'open' check (status in ('open','resolved')),
  created_at timestamptz not null default now()
);

-- ---------- 交換トークン ----------
create table public.exchange_tokens (
  token text primary key,
  owner_id uuid not null references public.profiles(id) on delete cascade,
  expires_at timestamptz not null,
  revoked boolean not null default false,
  use_count int not null default 0,
  created_at timestamptz not null default now()
);
create index exchange_tokens_owner_idx on public.exchange_tokens (owner_id);

-- ---------- 交換の記録 ----------
-- user_a は常に小さい方のUUID、user_b は大きい方。
-- これで「AとBの組は1行まで」を主キーで強制できる。
create table public.exchanges (
  id uuid primary key default gen_random_uuid(),
  user_a uuid not null references public.profiles(id) on delete cascade,
  user_b uuid not null references public.profiles(id) on delete cascade,
  first_met_at timestamptz not null default now(),
  last_exchanged_at timestamptz not null default now(),
  check (user_a < user_b),
  unique (user_a, user_b)
);

-- ブロックと同時に交換記録を削除
create or replace function public.on_block_created()
returns trigger language plpgsql security definer set search_path = public as $$
begin
  delete from public.exchanges
   where (user_a = least(new.blocker_id, new.blocked_id)
      and user_b = greatest(new.blocker_id, new.blocked_id));
  return new;
end;
$$;
create trigger after_block_insert
  after insert on public.blocks
  for each row execute function public.on_block_created();

-- RPC：公開カードの取得
-- =============================================
create or replace function public.get_public_card(p_public_id text)
returns jsonb language plpgsql security definer set search_path = public as $$
declare
  prof public.profiles%rowtype;
  viewer uuid := auth.uid();
  result jsonb;
begin
  select * into prof from public.profiles where public_id = p_public_id;
  if not found then return null; end if;

  -- 表示名が未設定なら公開しない
  if prof.display_name = '' then return null; end if;

  -- 訪問者がブロックされていたら「存在しない」扱い
  if viewer is not null and exists (
    select 1 from public.blocks
    where blocker_id = prof.id and blocked_id = viewer
  ) then
    return null;
  end if;

  result := jsonb_build_object(
    'public_id',    prof.public_id,
    'card_no',      prof.card_no,
    'display_name', prof.display_name,
    'comment',      prof.comment,
    'type_code',    prof.type_code,
    'axes', jsonb_build_object(
      'pe', prof.axis_pe, 'sg', prof.axis_sg,
      'lf', prof.axis_lf, 'ca', prof.axis_ca),
    'hyakumeizan_done',
      (select count(*) from public.climbed_mountains c
        join public.mountains m on m.id = c.mountain_id
       where c.user_id = prof.id and m.is_hyakumeizan),
    'climbed',
      coalesce((select jsonb_agg(jsonb_build_object(
          'name', m.name, 'hyaku', m.is_hyakumeizan) order by m.elevation desc nulls last)
        from public.climbed_mountains c
        join public.mountains m on m.id = c.mountain_id
       where c.user_id = prof.id), '[]'::jsonb)
  );

  -- 閲覧者との交換状態も返す（ボタン表示の切り替えに使う）
  if viewer is not null and viewer <> prof.id then
    result := result || jsonb_build_object('exchanged', exists (
      select 1 from public.exchanges
      where user_a = least(viewer, prof.id) and user_b = greatest(viewer, prof.id)));
  end if;

  return result;
end;
$$;
grant execute on function public.get_public_card(text) to anon, authenticated;

-- =============================================
-- RPC：交換トークンの発行
-- =============================================
create or replace function public.issue_exchange_token()
returns jsonb language plpgsql security definer set search_path = public as $$
declare
  me uuid := auth.uid();
  t text;
  exp timestamptz := now() + interval '10 minutes';
begin
  if me is null then raise exception 'not authenticated'; end if;

  -- 表示名が未設定のうちは交換できない
  if (select display_name from public.profiles where id = me) = '' then
    raise exception 'profile not ready';
  end if;

  -- 既存の有効なトークンを無効化（同時に複数出さない）
  update public.exchange_tokens
     set revoked = true
   where owner_id = me and revoked = false and expires_at > now();

  loop
    t := public.random_token(16);
    exit when not exists (select 1 from public.exchange_tokens where token = t);
  end loop;

  insert into public.exchange_tokens (token, owner_id, expires_at)
  values (t, me, exp);

  return jsonb_build_object('token', t, 'expires_at', exp);
end;
$$;
grant execute on function public.issue_exchange_token() to authenticated;

-- =============================================
-- RPC：交換の実行
-- =============================================
create or replace function public.redeem_exchange_token(p_token text)
returns jsonb language plpgsql security definer set search_path = public as $$
declare
  me uuid := auth.uid();
  tok public.exchange_tokens%rowtype;
  a uuid; b uuid;
  is_new boolean;
begin
  if me is null then raise exception 'not authenticated'; end if;

  select * into tok from public.exchange_tokens where token = p_token;
  if not found then return jsonb_build_object('ok', false, 'reason', 'not_found'); end if;
  if tok.revoked then return jsonb_build_object('ok', false, 'reason', 'revoked'); end if;
  if tok.expires_at <= now() then return jsonb_build_object('ok', false, 'reason', 'expired'); end if;
  if tok.owner_id = me then return jsonb_build_object('ok', false, 'reason', 'self'); end if;

  -- どちらかがブロックしていたら交換できない
  if exists (
    select 1 from public.blocks
    where (blocker_id = tok.owner_id and blocked_id = me)
       or (blocker_id = me and blocked_id = tok.owner_id)
  ) then
    return jsonb_build_object('ok', false, 'reason', 'blocked');
  end if;

  -- 表示名が未設定なら交換できない
  if (select display_name from public.profiles where id = me) = '' then
    return jsonb_build_object('ok', false, 'reason', 'profile_not_ready');
  end if;

  a := least(me, tok.owner_id);
  b := greatest(me, tok.owner_id);

  insert into public.exchanges (user_a, user_b)
  values (a, b)
  on conflict (user_a, user_b)
    do update set last_exchanged_at = now()   -- first_met_at は上書きしない
  returning (xmax = 0) into is_new;

  update public.exchange_tokens
     set use_count = use_count + 1
   where token = p_token;

  return jsonb_build_object(
    'ok', true,
    'is_new', is_new,
    'partner', (select public_id from public.profiles where id = tok.owner_id));
end;
$$;
grant execute on function public.redeem_exchange_token(text) to authenticated;

-- =============================================
-- RPC：自分のコレクション取得
-- =============================================
create or replace function public.get_my_collection()
returns jsonb language plpgsql security definer set search_path = public as $$
declare me uuid := auth.uid();
begin
  if me is null then raise exception 'not authenticated'; end if;

  return coalesce((
    select jsonb_agg(jsonb_build_object(
      'public_id',    p.public_id,
      'card_no',      p.card_no,
      'display_name', p.display_name,
      'comment',      p.comment,
      'type_code',    p.type_code,
      'axes', jsonb_build_object(
        'pe', p.axis_pe, 'sg', p.axis_sg, 'lf', p.axis_lf, 'ca', p.axis_ca),
      'hyakumeizan_done',
        (select count(*) from public.climbed_mountains c
          join public.mountains m on m.id = c.mountain_id
         where c.user_id = p.id and m.is_hyakumeizan),
      'first_met_at', e.first_met_at
    ) order by e.first_met_at desc)
    from public.exchanges e
    join public.profiles p
      on p.id = case when e.user_a = me then e.user_b else e.user_a end
   where me in (e.user_a, e.user_b)
  ), '[]'::jsonb);
end;
$$;
grant execute on function public.get_my_collection() to authenticated;
